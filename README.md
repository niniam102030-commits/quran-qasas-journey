# سفر قرآنی: سامانه تخصصی یادگیری واژگان سخت سوره مبارکه قصص (ویژه فارسی‌زبانان)

این پروژه، نسخه اختصاصی‌سازی‌شده اپلیکیشن قرآن بر محور **سوره مبارکه قصص (سوره ۲۸ قرآن کریم)** است که با تکیه بر تحلیل زبان‌شناختی و ریشه‌شناسی تطبیقی عربی-فارسی، برای شناسایی و تسلط بر واژگان دشوار، لغات کم‌تکرار و به‌ویژه **تله‌های معنایی (False Friends)** طراحی شده است.

---

## 🌟 چرا سوره قصص و تله‌های معنایی برای فارسی‌زبانان؟

در زبان فارسی، صدها واژه با ریشه عربی وارد شده‌اند؛ اما در گذر قرن‌ها، برخی از این واژه‌ها دچار **تغییر معنایی (Semantic Shift)** یا انحصار معنایی شده‌اند. هنگامی که یک فارسی‌زبان با این واژه‌ها در سوره قصص روبرو می‌شود، ذهن ناخودآگاه معنای رایج فارسی را جایگزین معنای اصیل قرآنی می‌کند.

### نمونه‌های بارز تله‌های معنایی سوره قصص در این برنامه:
1. **«فَارِغًا» (آیه ۱۰)**:
   - *تصور فارسی*: آسوده‌خاطر، بی‌خیال و تمام‌کننده کار («خیالم فارغ شد»).
   - *معنای اصیل وحی*: دل مادر موسی از هوش، شکیبایی و آرامش تهی و خالی شد و از شدت بی‌تابی نزدیک بود فریاد بزند.
2. **«شِيعَتِهِ» (آیه ۱۵)**:
   - *تصور فارسی*: انحصار در مذهب تشیع در عصر متأخر.
   - *معنای اصیل وحی*: گروه همراه، پیرو و هم‌کیش (مردی از قوم بنی‌اسرائیل که همراه موسی بود).
3. **«فَوَكَزَهُ» (آیه ۱۵)**:
   - *معنای اصیل وحی*: با مشت بر سینه زدن برای دفع مهاجم بدون نیت قتل؛ واژه‌ای اختصاصی و نادر در قرآن.
4. **«تَذُودَانِ» (آیه ۲۳)**:
   - *تصور فارسی*: چریدن، دوشیدن شیر، یا فرار کردن (خلط لفظی با ذوب یا دویدن).
   - *معنای اصیل وحی*: بازداشتن و جلوگیری کردن با حیا از اختلاط گوسفندانشان با گله مردان نامحرم.
5. **«اسْتَأْجِرْهُ» (آیه ۲۶)**:
   - *تصور فارسی*: در فارسی مدرن «اجیر کردن» بار منفی و مزدورانه دارد.
   - *معنای اصیل وحی*: استخدام محترمانه بر اساس شایسته‌سالاری («إِنَّ خَيْرَ مَنِ اسْتَأْجَرْتَ الْقَوِيُّ الْأَمِينُ»).
6. **«تَصْطَلُونَ» (آیه ۲۹)**:
   - *تصور فارسی*: صلح کردن یا نماز خواندن (صلاة).
   - *معنای اصیل وحی*: گرم شدن با آتش در سرمای استخوان‌سوز صحرا (ریشه ص‌ل‌ی).
7. **«جَانٌّ» (آیه ۳۱)**:
   - *تصور فارسی*: جن و پری و موجودات نامرئی ماورایی.
   - *معنای اصیل وحی*: ماری باریک، سبک‌بال، بسیار چابک و پرجهش در صحرا.
8. **«لَتَنُوءُ» (آیه ۷۶)**:
   - *تصور فارسی*: ناله کردن یا نوحه خواندن.
   - *معنای اصیل وحی*: سنگینی بیش از حدی که پشت گروهی از پهلوانان را خم کرده و به زانو درمی‌آورد.
9. **«الْعُصْبَةِ» (آیه ۷۶)**:
   - *تصور فارسی*: افراد خشمگین و عصبانی!
   - *معنای اصیل وحی*: گروه پیوندیافته از مردان دلاور و تنومند (از ۱۰ تا ۴۰ نفر).
10. **«فَخَسَفْنَا» (آیه ۸۱)**:
    - *تصور فارسی*: خسوف و ماه‌گرفتگی نجومی.
    - *معنای اصیل وحی*: شکافتن و فرورفتن زمین و بلعیدن قارون با تمام کاخ و گنجینه‌هایش.

## 🗺️ ۵ منزلگاه نقشه داستانی سوره قصص

سیر یادگیری کاربر در این اپلیکیشن مانند یک نقشه جغرافیایی-معنوی در قالب ۵ منزلگاه چیده شده است:
1. **قصر فرعون و کرانه نیل**: تولد، افکندن به نیل و آرامش‌بخشی به دل مادر موسی.
2. **دروازه شهر و گریز در تاریکی**: استغاثه مظلوم، مشت ناخواسته موسی و هجرت با بیم و امید.
3. **چاه آب مَدین و سایه‌سار نخل‌ها**: حیا و ادب دختران شعیب، سقایت، و استخدام نیروی امین و نیرومند.
4. **کوه طور و کرانه وادی مقدس**: آتش در تاریکی بیابان، اخگر آتش («جَذْوَةٍ»)، گرم شدن («تَصْطَلُونَ») و اعجاز عصا.
5. **کاخ قارون و گنج‌های سنگین**: سرمستی ثروت، کلیدهای توان‌فرسا و عبرت ابدی عذاب خسف.

## 🎮 موتور ۴ لایه چالش‌ها (Pedagogical Engine)

هر درس در این برنامه از چهار لایه تمرینی عبور می‌کند:
1. **لایه اول (Morphology De-Gluing یا Audio Cloze)**: پیوند صوت منشاوی با متن آیه یا کالبدشکافی قطعات.
2. **لایه دوم (Morphology De-Gluing)**: تفکیک پیشوندها، ریشه سه‌حرفه و ضمایر به صورت کشیدنی و پازلی.
3. **لایه سوم (False Friend Hunter)**: شکار تله‌های ذهنی زبان فارسی در انتخاب معانی دقیق قرآنی.
4. **لایه چهارم (Verse Builder)**: بازسازی کامل آیه بر اساس هندسه فهم و تدبر کلمات.

## 📱 بیلد و انتشار اندروید (Android Build & Release Guide)

پروژه به طور کامل با Capacitor هماهنگ و تنظیم شده است (`android/` و `capacitor.config.ts`). تمام محتوای ۶۶ فایل، قلم‌های اصیل مصحف و متن ترجمه در پوشه محلی `android/app/src/main/assets/public/` به شکل ۱۰۰٪ آفلاین ذخیره شده‌اند.

### پیش‌نیازها:
- **Java Development Kit (JDK)**: نسخه ۱۷ یا ۲۱ (تنظیم متغیر محیطی `JAVA_HOME`).
- **Android SDK**: با Platform نسخه ۳۶ و Build-Tools متناسب (تنظیم متغیر محیطی `ANDROID_HOME`).
- یا نصب نرم‌افزار **Android Studio**.

### ۱. به‌روزرسانی و همگام‌سازی کد وب در پروژه اندروید:
```powershell
npm run cap:build
```
این دستور پروژه وب را کامپایل کرده و پوشه `dist` را به طور خودکار در پروژه نیتیو اندروید سینک می‌کند.

### ۲. ساخت خروجی دیباگ (Debug APK):
اگر Android Studio را باز کنید:
```powershell
npx cap open android
```
یا با خط فرمان در پوشه `android`:
```powershell
cd android
.\gradlew.bat assembleDebug   # در ویندوز
./gradlew assembleDebug        # در لینوکس / مک
```
فایل خروجی دیباگ در مسیر زیر ایجاد می‌شود:
`android/app/build/outputs/apk/debug/app-debug.apk`

برای دسترسی سریع می‌توانید آن را در پوشه `release/` با نام `qasas-debug.apk` کپی کنید:
```powershell
Copy-Item android/app/build/outputs/apk/debug/app-debug.apk release/qasas-debug.apk
```

### ۳. ساخت نسخه نهایی و امضاشده (Release Signed APK / AAB):
برای انتشار در مارکت‌های اندروید (کافه‌بازار، مایکت، گوگل‌پلی):

#### الف) ساخت کلید اختصاصی امضا (Keystore):
```powershell
keytool -genkey -v -keystore release/qasas-release-key.jks -keyalg RSA -keysize 2048 -validity 10000 -alias qasas-key
```

#### ب) ساخت بسته نرم‌افزاری (AAB برای گوگل‌پلی یا APK برای بازار و مایکت):
```powershell
cd android
.\gradlew.bat bundleRelease    # خروجی AAB
.\gradlew.bat assembleRelease  # خروجی APK
```

#### ج) امضای فایل خروجی با `apksigner` یا `zipalign`:
```powershell
zipalign -v -p 4 android/app/build/outputs/apk/release/app-release-unsigned.apk release/qasas-release-aligned.apk
apksigner sign --ks release/qasas-release-key.jks --ks-key-alias qasas-key --out release/qasas-release.apk release/qasas-release-aligned.apk
```

## 🧪 دستورات تضمین کیفیت و تست‌ها (Quality Assurance)

تمام خطوط محتوا، تایپ‌ها، تست‌های واحد و لینتر پروژه ۱۰۰٪ سبز هستند:
```powershell
npm run content:all   # ادغام ۲۲ واحد و اعتبارسنجی سخت‌گیرانه ۶۸۲۳ سوال و رفرنس‌ها
npm run build         # بررسی تایپ‌اسکریپت و بیلد نهایی وب
npm test              # اجرای ۲۴ تست واحد (الگوریتم FSRS، گریدینگ، دیتابیس، استور)
npm run lint          # بررسی کیفی با oxlint (بدون خطا)
```
