# راهنمای اجرا (به ترتیب)

این سه سند با هم کار می‌کنند:

- `01-content-prompt.md`: پرامپت هوش مصنوعی قوی شما برای ساختن بانک سوال
- `02-antigravity-spec.md`: دستور کار دقیق تغییرات کد برای ایجنت Antigravity (دارای اینترنت)

## مراحل

1. **ایجنت Antigravity:** فایل `02-antigravity-spec.md` را به آن بدهید و بگویید «فاز ۱ و ۲ را اجرا کن». خروجی این دو فاز عبارت است از `public/content/base/*.json`، پوشه‌ی `input/` و اعتبارسنج. فازهای ۳ تا ۶ را هم همان‌جا ادامه دهید.
2. **هوش مصنوعی تولید محتوا:** `01-content-prompt.md` را به‌عنوان دستورالعمل بدهید. برای هر واحد (u_p385a، u_p385b، …) سه نوبت جدا بدهید: ورودی `input/<unitId>.input.json` + عبارت `PART A`، سپس `PART B`، سپس `PART C`. خروجی هر نوبت را در `public/content/units/<unitId>.part<X>.json` ذخیره کنید.
3. **اعتبارسنجی:** `npm run validate:content`. خطاها را به همان هوش مصنوعی برگردانید («این سوال‌ها خطا دارند، فقط همین‌ها را اصلاح کن»).
4. **ساخت مانیفست:** `node scripts/build-manifest.mjs`، سپس اجرای اپ.

## نکات مهم

- از **واحد اول** شروع کنید و پیش از ادامه‌ی همه‌ی ۲۴ واحد، کیفیت خروجی را روی واحد اول بسنجید (پاسخ‌های یکتا، انحرافی‌های خوب، حجم).
- برای واحدهای بعد، ایجنت `earlierHardWords` را با کلمات سخت واحدهای ساخته‌شده به‌روز می‌کند (`npm run build:inputs`).
- مبنای متن و ترجمه همیشه فایل base است؛ هرگز از خروجی AI برای اصلاح متن قرآن استفاده نکنید.
