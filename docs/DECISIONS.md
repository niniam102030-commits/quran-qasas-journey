# تصمیمات و مستندات فنی پروژه سوره مبارکه قصص

این سند کلیه تصمیمات مهندسی، منابع داده‌ای و مراجع اعتبارسنجی پروژه یادگیری و حفظ سوره مبارکه قصص را ثبت می‌کند.

---

## ۱. منبع داده‌های پایه متن و رسم‌الخط قرآن
- **متن رسم‌الخط عثمانی و چیدمان مصحف مدینه (۱۵ خطی)**:
  - منبع: **Quran.com API v4** (`verses/by_chapter/28` با پارامترهای `words=true, word_fields=text_uthmani,page_number,line_number`).
  - اعتبارسنجی: ۸۸ آیه کامل استخراج شد.
  - آیه ۱ سوره در صفحه ۳۸۵، خط ۱۰ شروع می‌شود (پس از اتمام سوره نمل و بسمله).
  - آیه ۸۸ سوره در صفحه ۳۹۶، خط ۷ پایان می‌یابد.
  - مجموعاً شامل ۲۲ واحد نصف‌صفحه‌ای استاندارد (صفحه ۳۸۵ تا ۳۹۶).

## ۲. منبع ترجمه فارسی
- **مبنای ترجمه**: **استاد حسین انصاریان** (شناسه `fa.ansarian` از پایگاه رسمی `tanzil.net`).
- اعتبارسنجی: ۸۸ آیه بدون کسری بارگذاری و راستی‌آزمایی شد.
- قانون تطبیق: تمامی قطعات ترجمه در چانک‌ها و صورت سوالات باید زیررشته دقیق از متن ترجمه انصاریان باشند.

## ۳. معماری تولید و اعتبارسنجی سوالات
- **جداسازی کامل متن از کدهای اجرایی**: هیچ متن طولانی قرآن یا بانک سوال در سورس‌کد جاوااسکریپت هاردکد نمی‌شود؛ همه چیز در فایل‌های استاندارد `public/content/units/<unitId>.part*.json` ذخیره و اعتبارسنجی می‌شود.
- **تولید ۳ بخشی (Part A, Part B, Part C)**: برای جلوگیری از قطع شدن پاسخ هوش مصنوعی در اثر سقف توکن خروجی:
  - **Part A (مراحل ۱ و ۲)**: فرهنگ واژگان کامل واحد (`lexicon`) + چانک‌بندی آیه (`chunks`) + سوالات معنای واژگان و تطبیق ترجمه آیه.
  - **Part B (مراحل ۳ و ۴)**: آیه‌چین و بازسازی متن + جای‌خالی‌های تدریجی (۲۵٪ تا ۸۰٪) + شناسایی آیات متشابه.
  - **Part C (مراحل ۵ تا ۸)**: زنجیره آیات قبل و بعد + حفظ دقیق شماره آیات + یادآوری پیوسته کل نیم‌صفحه + آزمون تسلط نهایی (مرحله ۸ با شرط قبولی ۹۰٪).
- **تصحیح پاسخ بر پایه شناسه و اندیس (Index-Based Grading)**:
  - برای جلوگیری از خطاهای رایج تفاوت نویسه‌های اعراب‌گذاری عربی یا فاصله‌ها، تصحیح با شناسه گزینه‌ها (`Option.id`) و اندیس کلمات (`wordIdx`) انجام می‌پذیرد.

## ۴. کارت‌های حافظه و سیستم تکرار فاصله‌دار (Universal FSRS)
- کلیدهای کارت حافظه:
  - `w:<wordId>`: معنای واژگان سخت
  - `vr:<ayahNumber>`: بازیابی متن آیه از حفظ
  - `vt:<ayahNumber>`: ترجمه آیه و پیوند متن با ترجمه انصاریان
  - `vn:<ayahNumber>`: تسلط بر شماره دقیق آیه
  - `sq:<ayahNumber>`: گذار از آیه به آیه بعد/قبل
  - `pg:<unitId>`: تسلط بر کل زنجیره نیم‌صفحه
- پارامتر نگهداری FSRS: **۰.۹۳** برای کارت‌های حفظ و شماره، **۰.۹۰** برای معنا و ترجمه.

## ۵. اسکریپت‌های سیستمی موجود
- `npm run fetch:base`: استخراج مجدد داده‌های پایه از Quran.com و Tanzil.
- `npm run build:inputs`: تولید فایل‌های آماده ورودی هوش مصنوعی (`input/<unitId>.input.json`).
- `npm run validate:content`: اعتبارسنجی ساختاری و محتوایی فایل‌های تولیدشده هوش مصنوعی با اعتبارسنجی سخت‌گیرانه (`--strict`).
